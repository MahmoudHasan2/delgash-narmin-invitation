# Delgash & Narmin — Hochzeitseinladung

صفحة دعوة عرس إلكترونية (ألماني) لدلغش ونرمين، صفحة وحدة ثابتة بدون أي باك-إند.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة كاملة (HTML + CSS + JS) |
| `8050c42b44e7726edc9cf0b98d0e4f2a.jpg` | صورة العروسين |
| `song.mp3` | أغنية الخلفية |

## التعديل
كل الإعدادات بكتلة `CONFIG` داخل `index.html`:
- `photo` — مسار صورة العروسين
- `song` — مسار الأغنية
- `date` — تاريخ ووقت العرس (الشهر يبدأ من 0، يعني 11 = ديسمبر)

الخريطة والعنوان (Gropiusstraße 2, 31137 Hildesheim) مكتوبين مباشرة بالـ HTML.

## التشغيل محلياً
افتح `index.html` بالمتصفح. الخطوط والخريطة بتحتاج إنترنت.

## النشر
الملفات ثابتة (static)، بتنرفع كما هي على `public_html` بالاستضافة.
