## English

An online wedding invitation page for Delgash & Narmin (German text). A single static page, no backend.

**Files**
| File | Purpose |
|---|---|
| `index.html` | The whole page (HTML + CSS + JS) |
| `8050c42b44e7726edc9cf0b98d0e4f2a.jpg` | Couple photo |
| `song.mp3` | Background music |

**Customizing:** all settings live in the `CONFIG` block inside `index.html`: `photo` (image path), `song` (audio path), `date` (date and time; months are 0-based, so 11 = December). The address and map are written directly in the HTML.

**Run locally:** open `index.html` in a browser. Fonts and the map need an internet connection.

**Deploying:** the files are static; upload them as-is to the web root (`public_html`).
